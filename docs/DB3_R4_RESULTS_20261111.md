# DB3 R4 — full-route expansion screen and bounded partial delivery

Date: 11 November 2026, Asia/Saigon. Recording: `20261030_134523.db3`.

**Outcome:** full-route screening and the D8 partial-delivery package are
complete. **A new accepted whole-scene reconstruction was not achieved.**
The measured expansion gates fail, so no additional Gaussian training or global
merge is promoted. The final independent audit is recorded below.

## Scope and acceptance

R4 asks for the best supported full-recording reconstruction, with weak regions
and incomplete coverage identified. The roadmap requires validated overlapping
geometry before Gaussian expansion; D8 allows a documented partial result when
global placement or scene-wide validation is absent. It does not permit merging
independent local worlds or treating finished training as accurate geometry.

The preceding cleanup verified the numerical input implementation and preserved
research evidence. It left physical calibration partial, global placement
unaccepted and the exhibit's independently frozen structures failing. The matte
candidate passes a narrower exposed-development appearance/consistency follow-up.
These findings are retained in [the R0–R3 cleanup](DB3_R0_R3_CLEANUP_20261111.md).

The R4 experiment extends **geometric evidence screening across the full route**.
It is not an executed global bundle adjustment, a new globally placed Gaussian
model or proof that the recording cannot ever be reconstructed better. Training
requires successful geometry and difficult-structure gates first. Missing checks
remain unknown; failed checks remain failed.

## Frozen experiment and controls

Fresh main artifacts: `results/db3_r4_20261111_v2/`.

- Freeze all **477 selected observations**, **4,764 native RGB identities**, the
  existing SDK-consistent calibration, original historical evaluation identities
  and all native geometry/final/buffer reservations before computing results.
- Test every adjacent selected interval whose entire native interval is eligible
  fitting data: **317 intervals**. The other **159 intervals** are explicitly
  excluded because of reservations. They are not measured geometry failures.
- Extract 3,000 SIFT features on corrected RGB. Fit on spatial tiles modulo 5
  other than zero, with zero tiles retained for checks. Use stable, measured depth
  only; no filling. Reconstruct dense depth from original read-only raw messages.
- Keep the existing conservative pair gate: at least 20 check matches, median
  separation <0.05 m, p90 <0.12 m, fitting hull >5%, information minimum
  eigenvalue >1 and condition number <1e7. Its pixel/range uncertainty model is
  assumed, not independently calibrated sensor covariance.
- Retry **every eligible failed interval** with actual native observations.
  Stop a chain at its first failed link. A chain of passing short links must also
  pass its endpoint checks. No excluded observation can enter a retry or fit.
- Preserve the frozen difficult exhibit checks and independent distributed global
  placement requirement. Pairwise connectivity cannot override either gate.
- Do not extend Gaussian training merely to improve a mean appearance score on
  rejected geometry. No thresholds are changed after seeing R4 results.

This is exposed development evidence. Check correspondences are disjoint from
the pair fit, but share the same sensor/calibration and can include descriptor
errors. Repeated/adaptive use of these observations does not create an untouched
test set. Endpoint support can be insufficient even when native tracking appears
plausible; rejection is not a unique drift diagnosis.

The 77 complete native chains illustrate why short-link connectivity alone is
insufficient. Seventy-two lack the required 20 stable endpoint correspondences;
five have enough but fail the separation limits. This does **not** prove all
chains have drift, all surfaces are wrong or all remaining poses are unrecoverable.
It establishes that this preregistered bounded expansion route did not supply
the required independent support. The 159 reserved intervals were not tested as
fitting bridges and must not be described as failed reconstruction.

**Decision:** retain the preserved full-route model as uncertain context and the
matte as a separate narrowly accepted local improvement. Keep exhibit experiments
unpromoted. There is no newly reconstructed or globally aligned full-scene model,
and no new 7k/15k/30k/120k training run. Longer training is not an appropriate
substitute for the failed geometry/structure requirements. R4's bounded screen
and fallback delivery are finished; its original scientific goal of an accepted
improved whole scene remains unmet. This is an explicit partial-result decision,
not a clean pass of R1–R4 or proof that recapture is the only possible solution.

Further whole-scene work needs stronger physically checked overlap and exhibit
backdrop/floor/wall/post support, or a separately validated alternative pose
branch. The current evidence does not identify calibration, timing, pose error,
visibility or appearance representation as a unique cause. Existing data and
failures remain available for that work. R5 may verify the delivered partial
models' viewer behavior; doing so cannot certify unresolved geometry.

## Engineering problems and verification

1. The initial preflight incorrectly expected dense `depth_m` in R1's sampled
   `points`/`depths` archive. It stopped before any geometry result. The corrected
   run reprojects the actual raw depth using the frozen SDK convention and
   preserves missing samples. Original RGB/sampled-depth hashes are checked.
   The failed namespace `results/db3_r4_20261111/` remains preserved.
2. A focused test run encountered eight setup errors from the default temporary
   directory permissions. With a fresh workspace `--basetemp`, **35 tests pass**,
   including four new fail-closed promotion/reservation controls. One pre-existing
   unknown pytest `env` configuration warning remains. No tests failed assertions.
3. The first rendering command omitted `.venv/Scripts` from PATH, making the
   installed Ninja executable unavailable. The runner now includes the venv and
   existing CUDA/MSVC toolchains. No package was installed or upgraded.
4. Concurrent packaging finished the renders/manifest before the route screen
   created `source_snapshot/`; its seal failed on the missing directory. The
   packager now creates that directory itself. A separate seal verified the
   existing complete 477-view manifest, model hashes and delivery files before
   freezing artifact hashes. Original failed logs and executed source are kept;
   the rendering evidence was not overwritten or relabeled as a new run.
5. Fresh expanded R0–R3 integrity audit passed in **36.05 s**, including the full
   17,129,000,960-byte raw recording SHA256, baseline/input hashes, finite selected
   models, reservations, replays, initializer/depth provenance and historical
   snapshots. A copy is inside the main R4 namespace. Raw SHA256 remains
   `60e3f253051fc282a61af7f6c9c5eef40830a12d42566b9eba0992463115bc52`.

Python compilation and PowerShell parsing pass. The independent R4 audit
**passes in 31.01 s**: all 1,688 input hashes and fit-only identities, all tile
exclusions, the complete selected/retry rosters, native transform composition,
delivery artifact hashes and exact frozen R0 camera/normalization matching.
Sixteen temporally distributed dense-depth inputs reproduce exactly from the raw
database with no filling. These checks establish evidence integrity and internal
consistency; they do not change the failed scientific expansion decision.
