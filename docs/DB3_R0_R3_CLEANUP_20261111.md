## Problems fixed

1. **Unsupported regions could disappear from paired acceptance.** The prior
   evaluator used `continue` for fewer than 100 sensor samples and tested only
   the remaining regions. Added `scripts/db3_acceptance.py`: every frozen view
   and region is required; insufficient, missing, nonfinite or invalid evidence
   fails. Duplicate/missing/changed source identities are rejected. Matching is
   by source-view name and metadata, rather than incidental array order.
2. **Confirmation ignored its loaded numerical rules.** Its comparisons used
   literal constants despite loading the frozen protocol. Confirmation now reads
   the frozen thresholds through the same comparison functions. Original depth
   improvement and narrower appearance/consistency follow-up remain distinct.
3. **Re-audits could overwrite historical evidence.** Both R0/R1 and R0–R3
   verifiers now write fresh output directories and verify historical snapshots
   against historical hashes. Confirmation refuses to overwrite a prior result
   and supports a separate output directory. The original campaign results and
   source snapshots were preserved.
4. **Integrity coverage was too narrow.** The expanded audit recomputes replay
   hashes from actual sequences; verifies initial-cloud/geometry-validation
   hashes; compares delivered metric poses to geometry/localization; checks all
   90k initializer coordinates/colors against the training sparse model; exactly
   reproduces the sampled training-depth subsets; and checks normalized camera
   transforms, source identities, viewer dataset/checkpoint paths and delivery
   hashes. It verified 95 matte and 91 exhibit cameras and 21 depth files per pilot.

These were verification weaknesses, not evidence that the existing saved results
were falsely promoted. Recomputing all original decisions with the stricter
logic leaves their pass/fail status unchanged. All saved coarse regions in the
paired studies have enough samples; the newly repaired missing-support path is
covered by regression tests.

## Exhibit support experiment

The prior support diagnosis did not separate loss from the 90k point cap,
voxelization, training-frame density and cross-view agreement. A new frozen-pose
diagnostic tested seven variants on exactly the existing 15 structure rectangles:

| Variant | Points |
|---|---:|
| Frozen selected initializer | 90,000 |
| Original supported observations before voxelization | 278,113 |
| Original supported 1 cm voxels, before the cap | 233,380 |
| Original fitting observations before support filtering | 400,679 |
| All 88 fitting frames, existing support rule | 1,295,670 |
| All 88 fitting frames, agreement additionally capped at 5 cm | 816,542 |
| All 88 fitting frames before support filtering | 1,657,738 |

All variants use fitting identities only; reserved/evaluation frames do not
contribute points, support or pose refinement. The optional stricter support cap
does not change the historical default. There is no evaluation-depth fitting,
new Gaussian training, hole filling or promotion of these diagnostic clouds.
The original voxel/cap recipe was reproduced exactly against the frozen 90k
initializer. The second run adds the uncapped-voxel control; the first run is
preserved separately.

Each cell below is **conditional point support coverage / median absolute depth
difference**, with points required within 2 pixels of the stable source sample.
These are not rendered-surface accuracy measurements, and the conditional sample
set changes with coverage. Low coverage is unknown, not proof of an empty surface.

| Fixed source structure | Frozen 90k | Uncapped original voxels | Dense supported | Dense support ≤5 cm |
|---|---:|---:|---:|---:|
| First backdrop | 0.83% / 0.164 m | 4.17% / 0.139 m | 52.50% / 0.205 m | 5.83% / 0.167 m |
| First floor | 22.17% / 0.038 m | 32.28% / 0.039 m | 58.75% / 0.039 m | 58.03% / 0.033 m |
| Middle post | 85.40% / 0.470 m | 100% / 0.036 m | 100% / 0.017 m | 100% / 0.015 m |
| Middle floor | 20.96% / 0.055 m | 35.01% / 0.056 m | 51.99% / 0.054 m | 31.38% / 0.039 m |
| Late wall | 97.30% / 0.104 m | 100% / 0.108 m | 100% / 0.109 m | 99.39% / 0.075 m |

**Finding:** the cap materially reduces support for the middle post; the uncapped
voxel control separates this from voxelization. However, removing the cap does
not resolve backdrop or floor support. More fitting frames raise coverage but do
not make all structures consistent. Stricter agreement reduces some differences
while nearly removing backdrop support. None of these variants resolves every
declared structure, and they are not equivalent-compute Gaussian comparisons.

**Decision:** retain the matte local candidate and uncertain whole-room baseline
as separate artifacts; retain both exhibit checkpoints as unpromoted experiments.
Do not justify expansion from mean RGB scores, point count or a successful hash
check. Support-preserving point selection is now a specific measured engineering
target, but still needs a bounded experiment under the cap and structure checks.
The remaining backdrop/floor/wall ambiguity requires stronger geometry evidence;
the current tests do not identify calibration, pose error or visibility as its
unique cause. This is an unresolved research result, not silently completed work.

Fresh visual review of the saved matte and 15k exhibit contact sheets agrees with
the recorded distinction: matte panel/text framing is visibly clearer; exhibit
mean perceptual improvements do not override the failed structure measurements.
No novel-view metric accuracy, interactive viewer test or collision-free route
was newly established.
