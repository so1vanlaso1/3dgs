# Dataset preparation and review

Read-only checks executed 9 November 2026. Full per-image identities, exact file SHA-256, dimensions, train/held-out labels and thumbnail-resolution Laplacian scores are under `results/school_dataset_audit_20261109/`; personal data under `results/school_personal_dataset_audit_20261109/`. Reproduce with `scripts/audit_school_datasets.py`. No dataset or saved evaluation split was modified.

Public sets contain Room 311 images (272/39), Counter 240 (210/30), Kitchen 279 (244/35), Bonsai 292 (255/37). Finite normalized poses and points and rotation orthogonality/determinant were checked. Exact duplicate file groups were absent in all four public sets. These checks establish loadable, structurally valid data, not physical pose accuracy or complete scene coverage.

Reviewed `results/school_dataset_audit_20261109/blur_candidate_contact_sheet.jpg`: three lowest sharpness scores per scene plus the highest-score control. Low-score Room images mostly show a blank wall above the sofa; texture content explains much of the low score. Counter closeups and Kitchen oblique tabletop views have less texture than their controls; Bonsai views differ in background and lighting. These resized previews do not justify deleting any candidate. Preserve the benchmark splits and report the flags; do not automatically remove texture-poor views which may constrain geometry. This is a targeted visual review, not a claim of pixel-level inspection of every original image.

Personal room input uses the existing cleaned RGB-D `data/realsense_20261030_134523_clean/rgbd/dataset` with 477 registered images (417/60 under the same every-eighth split). Existing `rejected_frames.json`, `cleaning_report.json`, `capture_manifest.json`, calibration files and frozen held-out source identities record the capture preparation. New QA verifies current readability and structural poses; it does not resolve the previously documented calibration/trajectory gate. No physical geometry correction is inferred from a finite pose matrix.

Capture plan for the final demonstration: prefer a small static matte object with all sides visible, consistent exposure and overlapping viewpoints at multiple heights; retain raw images/calibration and select the evaluation identities before any tuning. Existing personal room data remain a challenging diagnostic scene rather than a certified geometry reference. If absolute geometric accuracy is required by the supervisor, obtain an independent reference instead of reporting self-consistency as accuracy.
